A folder (the vault) with a pencil and a pen standing in it, leaning apart: Excalidraw's crossed tools, crossed inside the folder. It's drawn with [rough.js](https://roughjs.com), the sketch renderer Excalidraw uses. The wordmark is set in Excalifont: "vault" in ink, "draw" in rose.

All files are in [`assets/brand/`](assets/brand/).

## Which file where

| Use | File |
| --- | --- |
| On a dark background | `svg/lockup-dark.svg`, `svg/mark-dark.svg`, `svg/wordmark-dark.svg` |
| On a light background | `svg/lockup-light.svg`, `svg/mark-light.svg`, `svg/wordmark-light.svg` |
| Narrow spaces, posters | `svg/lockup-stacked-*.svg` |
| One colour | `*-black` on light, `*-white` on dark |
| 16–32 px | `svg/mark-small-*.svg` |
| App icon (macOS grid) | `svg/app-icon-dark.svg`, `png/app-icon-1024.png` |
| Favicon | `svg/favicon.svg` (follows light/dark), `favicon.ico` |
| Avatar | `png/github-avatar-500.png` |
| Link previews | `png/social-card-1200x630.png` |
| Terminal | `ascii/wordmark-ansi.txt` (colour), `ascii/wordmark-blocks.txt` |
| Plain text | `ascii/mark.txt`, `ascii/mark-small.txt`, `ascii/lockup.txt` (7-bit ASCII) |

The SVGs are plain paths with transparent backgrounds: no fonts, filters or scripts. They look the same in browsers, GitHub, Figma, Inkscape and print.

## Rules

- **Clear space:** keep at least a quarter of the mark's width free around the logo.
- **Minimum size:** use the full mark from 32 px up, and the small mark below that. Keep the wordmark at least 14 px tall.
- **Don't:**
  - recolour it outside these palettes
  - stretch, rotate, outline or add shadows to it
  - retype the wordmark in another font
  - put the colour logo on busy photos; use the black or white version there
