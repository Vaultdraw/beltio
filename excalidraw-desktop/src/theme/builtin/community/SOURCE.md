# Community palettes: source

Three palettes in this folder come from Noctalia's community palette repository:

- Repository: https://github.com/noctalia-dev/community-palettes
  (formerly `noctalia-colorschemes`)
- Commit: `a88b6364057c042ff81c49f085d7957c2575dd0f` (branch `main`, committed 2026-10-10)
- Downloaded: 2026-10-13

| File | Source palette | Note |
| --- | --- | --- |
| `solarized.json` | `Solarized` | unchanged |
| `everforest.json` | `Everforest Alt` | `name` set to "Everforest": its dark background `#2d353b` and light `#fffbef` are Everforest's own medium background and light paper |
| `one-dark.json` | `One` | `name` set to "One Dark": its accent `#61afef` is One Dark's blue |

The palettes were imported with `scripts/import-noctalia-palettes.mjs`; colours were
lower-cased and keys the theme engine does not use were dropped. No colour
value was edited by hand.
